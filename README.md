# TopUpBay

Instant game top-ups, gift cards, and digital keys marketplace. Built with Next.js 16, React 19, Tailwind CSS 4, and TypeScript.

## Design System

This project uses a **Driffle-inspired design system** featuring:

- **Dark theme** with `#0c0c0c` primary background
- **Onest** heading font + system font stack for body
- **Red accent** (`#df0000`) for CTAs and brand highlights
- **Rounded corners** (16px+ for cards, 8px for buttons)
- **20px base spacing unit**

See `src/app/globals.css` for the full design token reference.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Scripts

- `pnpm dev` — Start development server
- `pnpm build` — Build for production
- `pnpm lint` — Run ESLint
- `pnpm start` — Start production server

## Tech Stack

- **Framework:** Next.js 16.2.4
- **UI:** React 19, Tailwind CSS 4
- **Icons:** Lucide React
- **Language:** TypeScript
